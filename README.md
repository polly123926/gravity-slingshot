# 重力彈弓 Gravity Slingshot 規格書

> 撰寫日期：2026-10-19

## 線上遊玩

把專案開啟 GitHub Pages 後，`index.html` 就是遊戲本體，直接用瀏覽器打開即可遊玩（支援電腦與手機）。

## 一、專案簡介

一款太空主題的物理小遊戲。玩家用彈弓的方式發射探測器，探測器經過星球附近時，軌跡會被星球周圍的重力吸引而彎曲。玩家要善用重力讓探測器繞過星球、飛進傳送門。

## 二、遊戲玩法

- 在畫面上按住往後拉，放開就發射探測器；拉得越長，力道越大
- 拉動時只顯示彈弓橡皮筋與力道百分比，**不顯示預測軌跡**
- 探測器受到所有星球的重力影響，飛行路線會被拉彎；離星球越近、星球質量越大，拉力越強
- 探測器飛進紫色傳送門即過關
- 撞到星球、飛出畫面或飛行超過 14 秒就算失敗，探測器自動回到發射台

## 三、天體種類

| 天體 | 外觀 | 效果 |
| --- | --- | --- |
| 行星 | 漸層彩色圓球 | 把探測器吸過去 |
| 反重力星 | 藍白色，向外擴散的波紋 | 把探測器推開；關卡開始時會彈出提示「這是反重力星，會把探測器推開！」 |
| 衛星 | 灰色小球，沿虛線軌道繞行星轉 | 會移動，需看準發射時機 |

## 四、關卡設計（共 3 關）

| 關卡 | 名稱 | 內容 |
| --- | --- | --- |
| 1 | 初次彈射 | 一顆行星擋在發射台與傳送門中間，學習讓軌跡繞彎 |
| 2 | 雙星迴廊 | 兩顆行星，傳送門在右上角，需借兩顆星的重力轉彎 |
| 3 | 衛星之舞 | 反重力星 + 行星 + 繞行衛星，考驗路線與時機 |

每一關都經程式模擬驗證：可以過關、可以拿滿 3 星，且直接瞄準傳送門發射無法過關（必須利用重力）。

## 五、計分方式

- 每關有 3 顆星星，探測器同一發收集到幾顆，就得幾星
- 記錄每關的發射次數
- 最佳成績（星數多者優先，同星數則發射次數少者優先）存在瀏覽器 localStorage

## 六、畫面流程

1. **遊戲說明**：一進入網頁就彈出，簡短說明操作與「重力會讓軌跡彎曲」
2. **主選單**：開始遊戲、選擇關卡、重看遊戲說明
3. **選關頁面**：三張關卡卡片，顯示各關最佳星數與發射次數，可自由選關
4. **遊戲畫面**：上方資訊列顯示關卡名稱、發射次數、本發星星數，以及「重來」「選關」按鈕
5. **過關畫面**：顯示得星與發射次數，可前往下一關、再玩一次或回選關
6. **全破畫面**：顯示三關總星數（滿分 9 星）與總發射次數

## 七、視覺風格

- 深色星空背景，閃爍星點與淡淡星雲
- 探測器飛行時留下發光尾跡，撞毀時有爆炸粒子
- 傳送門為旋轉的紫色光環

## 八、技術規格

- 單一 `index.html` 檔案，CSS 與 JavaScript 皆寫在檔案內，不依賴外部資源
- 使用 HTML Canvas 繪圖，遊戲世界固定 1000 × 600，依視窗大小等比例縮放
- 使用 Pointer Events，同時支援滑鼠與手機觸控
- 物理計算：每秒 240 次小步更新，引力與距離平方成反比；重力強度可由程式中的 `GRAVITY` 常數調整（目前為 1.6）
- 部署：上傳至 GitHub，以 GitHub Pages 公開

## 九、開發過程中的調整紀錄

- 關卡數由原構想 5 關調整為 3 關；取消預測輔助線與太空小知識；加入選關功能
- 新增開場遊戲說明，之後依回饋精簡為三行重點加一句重力提醒
- 降低難度：傳送門與星星判定範圍加大、行星縮小、衛星變慢
- 重力強度提高為 1.6 倍，讓軌跡彎曲更明顯
- 反重力星推力調小，並加入反重力星的彈出提示
